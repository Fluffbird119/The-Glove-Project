Okay so I made this project way back in my senior year of high school where I wanted to see if I could make a custom controller using gyroscopes and gloves for a custom Unity game.

My end product was two gloves each with an Arduino nano, MPU6050 gyroscope and the right hand glove had a joystick under the pointer and middle finger (you can see all this in the pictures and videos).

It worked fine... It was my first time using Arduinos and the whole process was a ton of fun so I figured I'd just upload everything on here so anyone on the Internet could see it.

As always if you do anything cool with this let me know!
